🌴 South Delights – South Indian Food Website

South Delights is a responsive food website that showcases the rich and authentic flavors of South Indian cuisine. The website presents popular dishes, a clean layout, and a modern UI built using HTML, Tailwind CSS, and JavaScript.

This project focuses on creating a visually appealing and responsive design while maintaining simple and clean code structure.

🚀 Features

🍛 Beautiful showcase of South Indian dishes

📱 Fully responsive layout (mobile, tablet, desktop)

🎨 Modern UI using Tailwind CSS

🧭 Navigation bar with burger menu for small screens

⚡ Smooth and simple JavaScript interactions

🖼️ Image-based food cards for better user experience

🛠️ Built With

HTML5

Tailwind CSS

JavaScript
